# NexaTech Linux Infrastructure 

## Overview

A hands-on Linux System administration project focused on building, securing,
managing and troubleshooting a simulated small buisiness infrastructure.

The project is developed over 2 months as preparation for the LFCS certification.

## Goals

- Build and administer Linux Systems.
- Manage users, groups and permissions.
- Configure storage, filesystems and networking.
- Manage services, processes and security.
- Automate administrative tasks using Bash.
- Practice Troubleshooting and recovery.
- Leran Git and Github workflows

## Environment 
- OS> Ubuntu Desktop 26.04 LTS
- Virtualization. Oracle VirtualBox 
-Shell. Bash
- Version control. Git 
- Hosting. Github.
